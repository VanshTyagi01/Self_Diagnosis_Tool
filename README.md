# Self_Diagnosis_Tool

## Overview

The Self Diagnosis Tool is an AI-powered web application designed to help users diagnose up to 42 types of diseases based on their symptoms. The tool asks a series of yes/no questions related to symptoms and provides a predicted disease based on the responses. This project aims to assist individuals in identifying potential health conditions early, enabling timely medical consultation.

## Features :

    Diagnoses 48 different diseases based on symptoms.

    Uses an AI-driven model for accurate predictions.

    Simple yes/no questionnaire format.

    User-friendly interface built with React (frontend) and Flask (backend)  [Comming Soon]

    Helps users become aware of possible health conditions before consulting a doctor.


## Disclaimer

This tool is not a substitute for professional medical advice. It is designed to provide preliminary insights based on AI predictions. Users should consult a healthcare professional for an accurate diagnosis and treatment.
